07 / REFLECTION

Key learnings & recommendations.

What worked

  • Video content can generate strong engagement.
  • Carousel formats can encourage product exploration.
  • Relevant fashion interests help build audience relevance.

What didn't work

  • Static creatives may receive lower interaction than dynamic formats.
  • Broad targeting can reduce relevance.
  • A short test window limits optimization time.

Future recommendations

  • Run A/B tests for visuals and copy.
  • Build retargeting audiences from website visitors.
  • Create separate festive and everyday campaigns.
  • Increase short-form video testing.
